# What is a Program?
A program is a set of instructions written in a programming language that tells a computer what to do. Programs are executable files that perform specific tasks or functions.
## Examples
- Web browsers (Chrome, Firefox)
- Text editors (VS Code, Notepad)
- Games
- Operating systems
- Mobile applications
## How Programs Work
1. Source code is written by programmers
2. Code is compiled or interpreted into machine-readable format
3. Computer executes the instructions
4. Results are displayed to the user
