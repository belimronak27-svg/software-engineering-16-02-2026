# How does GIT improve collaboration in a software development team?

## Version Control
Git tracks all code changes, allowing team members to see who modified what and when. This prevents accidental overwrites and enables easy rollback to previous versions.

## Branching & Merging
Developers can work on separate branches independently, then merge changes back to the main codebase. This reduces conflicts and allows parallel development.

## Code Review
Pull requests enable team members to review code before merging, ensuring quality and knowledge sharing across the team.

## Distributed Development
Each developer has a complete repository locally, allowing work offline and reducing dependency on a central server.

## Conflict Resolution
Git provides tools to identify and resolve code conflicts, making it easier to integrate changes from multiple developers.

## Team Communication
Commit messages and pull request discussions document decisions and changes, creating a project history and knowledge base.

## Integration with Tools
Git integrates with CI/CD pipelines, project management tools, and code hosting platforms, streamlining the development workflow.
