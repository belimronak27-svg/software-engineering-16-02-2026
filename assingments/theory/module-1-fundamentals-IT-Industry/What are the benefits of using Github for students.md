# What are the benefits of using Github for students?

## Benefits of GitHub for Students

 **Version Control**: Learn and practice Git fundamentals with real-world workflows
 **Portfolio Building**: Showcase projects to potential employers and collaborators
 **Collaboration**: Work with teammates on assignments and open-source projects
 **Code Review**: Receive feedback on code quality through pull requests
 **Free Private Repositories**: Host unlimited public and private projects
 **GitHub Education Pack**: Access free developer tools and resources
 **Community Learning**: Contribute to open-source and learn from others
 **Career Opportunities**: Network with developers and recruiters
 
## Types of Software

 **System Software**: Operating systems, compilers, databases
 **Application Software**: Productivity tools, games, browsers
 **Open Source Software**: Freely available and modifiable code
 **Proprietary Software**: Licensed and restricted distribution
 **Web Applications**: Cloud-based software accessible via browsers
 **Mobile Applications**: Software designed for mobile devices
