 ## TCP/IP Model 
 -A conceptual framework for understanding network communication
  The TCP/IP model is a four-layer model that describes how data is transmitted
  over networks. It provides the foundational architecture for modern internet
  communication.
  
 ## Layer 1: Link Layer (Network Interface Layer)
 - Handles physical transmission of data over network hardware
 - Manages MAC addressing and physical device drivers
 - Examples: Ethernet, WiFi (IEEE 802.11)
 
 ## Layer 2: Internet Layer
 - Responsible for routing data packets across networks
 - Manages IP addressing and logical routing
 - Key protocols: IP (IPv4, IPv6), ICMP, IGMP

 ## Layer 3: Transport Layer
 - Provides end-to-end communication and data flow control
 - Ensures reliable or fast delivery of data
 - Key protocols: TCP (Transmission Control Protocol), UDP (User Datagram Protocol)
 
## Layer 4: Application Layer
 - Provides network services directly to user applications
 - Handles data formatting, encryption, and user interaction
 - Examples: HTTP/HTTPS, FTP, SMTP, DNS, SSH, Telnet
 
 ## Client-Server Architecture:
 - Clients initiate requests to Servers
 - Servers listen for and respond to client requests
 - Communication occurs through defined protocols across these TCP/IP layers
