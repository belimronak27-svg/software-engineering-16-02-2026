# Types of Software Maintenance

Software maintenance is categorized into four main types:

## 1. Corrective Maintenance
Fixes bugs and defects discovered after software deployment. Focuses on resolving issues that affect functionality.

## 2. Adaptive Maintenance
Updates software to work with new environments, platforms, or technologies. Examples include OS upgrades or dependency updates.

## 3. Perfective Maintenance
Enhances existing features and improves performance, usability, or efficiency based on user feedback and evolving requirements.

## 4. Preventive Maintenance
Refactors code, updates dependencies, and improves architecture to prevent future issues and reduce technical debt.

## Key Points
- **Corrective** = Fix problems
- **Adaptive** = Adjust to new environments
- **Perfective** = Improve and enhance
- **Preventive** = Avoid future issues
