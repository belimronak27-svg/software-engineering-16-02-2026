# Differences Between Open-Source and Proprietary Software

## Open-Source Software
- **Source Code**: Publicly available and can be viewed, modified, and distributed
- **Cost**: Usually free
- **Licensing**: Typically GPL, MIT, Apache, or similar licenses
- **Community**: Driven by community contributions
- **Transparency**: Code is transparent and auditable
- **Examples**: Linux, Git, VS Code, Python

## Proprietary Software
- **Source Code**: Closed and not available to users
- **Cost**: Usually requires purchase or subscription
- **Licensing**: Proprietary license agreements
- **Control**: Owned and controlled by a single company
- **Updates**: Controlled by vendor
- **Examples**: Microsoft Windows, Adobe Creative Suite, macOS

## Key Differences Table

| Aspect | Open-Source | Proprietary |
|--------|-------------|------------|
| Source Code Access | Public | Restricted |
| Modification | Allowed | Not allowed |
| Cost | Free/Low cost | Paid |
| Support | Community | Vendor |
| Customization | High | Low |

# Git and GitHub Training

## Git Basics
- **Version Control System**: Track changes in code
- **Local Repository**: Work offline and commit changes
- **Branches**: Create isolated development paths
- **Commits**: Save snapshots of your work

## GitHub Essentials
- **Remote Repository**: Cloud-based code hosting
- **Collaboration**: Work with team members
- **Pull Requests**: Review and merge code changes
- **Issues & Projects**: Track work and bugs
