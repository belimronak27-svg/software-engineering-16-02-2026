# World Wide Web & How Internet Works
## The Internet
### Definition
A global system of interconnected computer networks that communicate using standardized protocols.
### Key Components
- **Servers**: Computers that host and serve data
- **Clients**: User devices that request data
- **Networks**: Connected infrastructure (ISPs, routers, cables)
- **Protocols**: Rules for data transmission (TCP/IP, DNS)
### How It Works
1. User initiates a request from a client device
2. Data is broken into packets
3. Packets travel through multiple networks
4. Packets reach the destination server
5. Server responds with requested data
6. Packets reassemble on the client device

## World Wide Web (WWW)
### Definition
An application layer service built on top of the Internet using HTTP/HTTPS protocols.
### Key Technologies
- **HTTP/HTTPS**: Protocol for transferring web pages
- **HTML**: Markup language for web content
- **URLs**: Addresses for locating resources
- **Web Browsers**: Software that interprets and displays web pages

## Key Differences
| Aspect | Internet | World Wide Web |
|--------|----------|----------------|
| Layer | Infrastructure | Application |
| Protocol | TCP/IP | HTTP/HTTPS |
| Purpose | Data transmission | Document sharing |
