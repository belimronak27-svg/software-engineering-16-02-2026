
# UML Diagrams

UML (Unified Modeling Language) provides a standardized way to visualize system architecture and design.

## UML Diagram Types

### Structural Diagrams

1. **Class Diagram**
    - Shows classes, attributes, methods, and relationships
    - Example: E-commerce system with Product, Order, and Customer classes

2. **Component Diagram**
    - Displays system components and dependencies
    - Example: Web application with UI, API, and Database components

3. **Deployment Diagram**
    - Illustrates hardware and software deployment
    - Example: Cloud infrastructure with servers and client devices

4. **Object Diagram**
    - Shows instances of classes at a specific point in time
    - Example: Customer object with specific attribute values

5. **Package Diagram**
    - Organizes model elements into packages
    - Example: System grouped into Frontend, Backend, Database packages

6. **Composite Structure Diagram**
    - Details internal structure of components
    - Example: Microservice architecture breakdown

### Behavioral Diagrams

1. **Use Case Diagram**
    - Shows interactions between actors and system
    - Example: Bank system with user login, withdraw, deposit use cases

2. **Sequence Diagram**
    - Depicts message flow between objects over time
    - Example: Order processing sequence from user to payment gateway

3. **State Machine Diagram**
    - Shows state transitions and events
    - Example: Order states: pending, processing, shipped, delivered

4. **Activity Diagram**
    - Represents workflow and process flow
    - Example: Approval workflow with decision points

5. **Communication Diagram**
    - Shows interactions between objects with numbering
    - Example: System communication paths

6. **Interaction Overview Diagram**
    - Combines multiple interaction diagrams
    - Example: Complex multi-step process overview
